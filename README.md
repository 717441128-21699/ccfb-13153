# 拉班舞谱三维工作室（Labanotation Studio）

面向舞蹈学院的拉班舞谱（Labanotation）教学与课题申报工具：在网页上按拉班记谱法
**竖排编辑舞谱**，实时驱动**三维人体**动画，并支持**逆向记谱**（摆三维姿势自动生成舞谱符号）。

纯 TypeScript + 原生 WebGL2 实现，零第三方 3D 引擎依赖。

## 功能对照需求

| 需求 | 实现 |
| --- | --- |
| 竖谱底读，格子里摆方向符号 | `StaffEditor` 画布竖谱，`beat=0` 在底部，向上阅读 |
| 高/中/低三层 | 27 方位 = 9 方位 × 3 层；层级用填充区分（低=实心、中=点阵、高=斜线） |
| 左右身体各列分开 | 四列布局：左支撑 \| 左手势 ‖ 右手势 \| 右支撑，中心轴分左右 |
| 支撑符号与手势符号区分 | `support` / `gesture` 两类列，腿走 IK、手臂走 FK |
| 小节线跟着拍子走 | 按 `beatsPerBar` 自动绘制小节线并标注小节号/拍号 |
| 符号拉长 = 动作持续久 | 拖动符号顶部手柄改变 `durationBeats`，符号纵向长度即时变化 |
| 谱面往上走一格三维人跟着动 | 播放头扫拍，`getPoseAtBeat` 平滑插值驱动骨骼 |
| 转身/跳跃/重心转移按符号算 | 转身累积 yaw；双脚取消生成空中区间 + 抛物线；重心落在支撑脚之间 |
| 手臂高中低方位用正向运动学摆到位 | `solveArmPose` 方位→肩肘欧拉角，沿关节层级 FK |
| 双人舞看出相对位置 | 多舞者 + 舞台站位偏移/朝向偏移，内置双人舞示例与"面对面" |
| 逆向：三维姿势自动写谱 | `posesToScore`：肢体向量逆映射 27 方位，游程编码生成长符号 |
| 64 小节翻动画 < 2 秒 | 实测 256 拍 / 512 符号编译 **≈15ms**（断言 < 2000ms） |
| 四人同屏 60 帧 | 实例化渲染；实测 4 舞者单帧采样+FK **≈0.24ms**，内置 FPS 表 |
| TS + WebGL2 | 严格模式 TS（`tsc --noEmit` 零错误）+ WebGL2 实例化胶囊/球 |

├── animation/

## 操作说明

- **放符号**：左侧选层级与方位（或转身/保持/取消），在竖谱对应列、对应拍点点击空白处放置。
- **拉长符号**：鼠标按住符号顶部手柄上下拖，长度即持续拍数；按住符号本体可上下移动起始拍。
- **切换列**：点击四列表头或谱面列，决定新符号落入哪条身体列。
- **播放**：空格键或播放按钮；下方滑块逐拍定位，红色虚线为播放头。
- **双人/四人**：右栏"载入双人舞"或"四人同屏压测"；舞者卡片可隐藏、设为面对面。
- **逆向记谱**：右栏进入姿态编辑 → 滑块摆关节角（三维实时预览）→ 逐拍"采集" → "生成舞谱"。
- **校验**：右栏实时显示同列时间重叠、越界等问题。

## 记谱约定

- 舞者本地坐标系：面朝 **−Z**，左侧 **−X**，上 **+Y**；正 yaw 为标准右手绕 +Y 旋转。
- 支撑层级映射骨盆基准高度：高（立半脚尖）/ 中（站立）/ 低（深蹲）。
- 双脚支撑同时为"取消"符号时判定为空中，按起跳/落地高度生成跳跃抛物线。
- 逆向记谱的腿层级由骨盆高度判定，手臂层级由肩→手向量的垂直分量判定。

## 浏览器兼容

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 现代版本）。
检测不到 WebGL2 时三维舞台显示降级提示，竖谱编辑、校验与逆向记谱仍可使用。
