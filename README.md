# 拉班舞谱三维记谱与动画系统

TypeScript + WebGL2 实现的拉班舞谱（Labanotation）记谱、三维人体动画与逆向记谱系统，面向舞蹈学院馆藏舞谱的数字化课题。

## 三个工作界面

| 页签 | 使用者 | 能力 |
| --- | --- | --- |
| **记谱编辑器** | 记谱老师 | 竖排七列谱面，按拉班格子摆放方向符号；高中低三层、左右身体各列、支撑/手势分列；小节线随拍号生成；符号拉长即动作持续 |
| **三维查看器** | 学生 | 舞谱向上走一格，三维人同步动作；走步、转身、跳跃、重心转移、手臂方位；含单/双/四人示例与实时帧率 |
| **姿势采集（逆向）** | 老师 | 在三维人身上用滑杆摆姿势，逐拍采样后自动反解为舞谱符号，可写回谱表并往返校验 |

## 启动

```bash
npm install

```

## 核心设计

### 舞谱数据模型
- **九方向 × 三层 = 27 方位**，每个方向符号映射到人体局部坐标的单位向量。
- **七列谱表**：左支撑、左腿、左臂、身体、右臂、右腿、右支撑；支撑符号与手势符号天然分列。
- **纵向为时间**，符号 `durationBeats` 即符号长度；小节线由拍号 `beatsPerBar` 自动绘制。
- 身体列承载转身（角度）、重心转移（方向）、跳跃（腾空高度）等非方向符号。

### 编译器（舞谱 → 动画）
逐谱表做有序状态机，按 1/4 拍固定网格采样：
1. **支撑脚锚定**：新支撑符号计算迈步目标，持续期内缓动滑入，双脚中点驱动髋部。
2. **两骨 IK**：余弦定理定弯折角，极向量投影定弯折平面，膝盖/肘自动偏向极点。
3. **手臂**：正向运动学摆到 27 方位目标，两骨求解保证手到位。
4. **转身**绕根节点偏航插值，角度走最短弧；**跳跃**用抛物线抬升骨盆与双脚；**重心转移**偏移髋部并联动脊柱前倾。

### 逆向记谱（动画 → 舞谱）
由关节世界位置反算相对骨盆、扣除朝向的肢体向量，量化到最近的 27 方位；同列相邻帧方位相同则合并为更长的符号。转身量按 1/8 圈（45°）吸附，跳跃按骨盆离地高度识别。

### 渲染性能
球、圆柱、盒三种几何体各建一份 VAO，所有舞者的所有骨节通过实例化矩阵共享同一批 draw call——四人 × 17 关节每帧仅 3 次实例化绘制。

## 验收指标（测试可复现）

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 64 小节四人谱编译 | ≤ 2000 ms | 约 80–130 ms（`test/timing.test.ts`） |
| 四人单帧采样 + 姿态解算 | 满足 60fps（<16.7ms） | < 4 ms（`test/performance.test.ts`） |
| 逆向往返 | 符号可重新编译且关节不发散 | `test/e2e.test.ts` 覆盖 |
| 动作正确性 | 脚贴地、手过肩、转身 90°、跳跃腾空 | `test/compiler.test.ts` 覆盖 |

## 记谱编辑器操作

- **双击**谱面空白：按左侧调色板当前设置在该列/拍放置符号。
- **拖动符号**：移动时间位置；**拖动底边手柄**：改变持续时长。
- **单击选中**后在右侧检查器改方向、层次、纹影、伸展度，或 Delete 删除。
- 撤销/重做、多舞者谱表、localStorage 持久化均在右侧面板。
- 底部三维预览随编辑防抖重编译，播放头红线与三维动作同步。

## 约定与边界

- 人体局部坐标：+X 右、+Y 上、+Z 后，面向 −Z（观众方向）。
- 骨架尺寸闭合：髋根高 0.95 m = 大腿 0.46 + 小腿 0.42 + 踝到地 0.07。
- 逆向量化是最近邻近似，复杂连续动运会被吸附到 27 方位；UI 输出最大偏差弧度供老师判断是否需要手工修正。
- 浏览器需支持 WebGL2（Chrome/Edge/Firefox 现代版本）。
